# Workspace UI QA captures

These screenshots were taken from the local Vite preview in bundled headless Chromium after exercising the tab-free goal overview, map navigation, goal search, and goal focus selection.

- `workspace-overview.png`: 1440 × 940
- `goal-map.png`: full-page map view at 1440 px wide
- `minimum-window-900px.png`: 900 × 680, the Tauri window's configured minimum width and height

The preview does not have Tauri's native bridge, so the visible runtime-offline notice is expected. The embedded runtime was smoke-tested separately. These captures are not screenshots of the native Tauri window.
