# KeplerV Judge Demo

`keplerv-judge-demo.mp4` is a narrated, illustrated product tour prepared from the current KeplerV UI and the checked-in Phase 5 / Phase 6 capability notes. It is not a screen recording.

The tour is intentionally explicit about what was and was not exercised: its coastal-resilience links are curated public examples; no live Muse/model run, outbound email, or external-agent contact occurred. The product flows are presented as UI/capability explanations, not as a claim that those actions succeeded in this recording.

## Files

- `keplerv-judge-demo.mp4` — H.264 video with narration
- `captions.srt` — captions for the narration
- `narration.txt` — voiceover script
- `frames/` — editable SVG storyboard frames and rendered PNGs
- `voice/` and `segments/` — generated narration audio and intermediate scenes
